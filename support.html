🚀 快速开始

如何开始第一次记录？

1. 确保您的 iPhone 和 Apple Watch 已配对

2. 在 Apple Watch 上打开双栖应用

3. 点击"开始"按钮开始记录

4. 活动结束后点击"结束"，数据会自动同步到 iPhone

需要授予哪些权限？

应用需要以下权限才能正常工作：

• 健康数据读取：读取心率和运动数据

• 健康数据写入：保存体能训练记录（可选）

• Face ID / Touch ID：保护应用访问（可选）

✨ 功能说明

阶段识别是如何工作的？

应用通过分析心率变化模式自动识别活动的不同阶段：

• 预热期：心率逐渐上升的阶段

• 高峰期：心率维持在较高水平

• 高潮期：心率达到峰值的阶段

• 恢复期：心率逐渐恢复的阶段

智能检测功能是什么？

智能检测功能可以从您的健康数据中识别可能遗漏的记录。当您打开应用时，如果检测到过去48小时内有符合特征的活动，会提示您是否添加记录。

此功能可以在设置中开启或关闭。

卡路里是如何计算的？

卡路里计算基于以下因素：

• 您的体重和年龄（在设置中填写）

• 活动时长

• 平均心率和峰值心率

• 运动强度

这是一个估算值，实际消耗可能有所不同。

🔒 隐私与安全

我的数据安全吗？

是的，非常安全。所有数据仅存储在您的设备本地：

• 我们没有服务器，不会上传任何数据

• 数据不会同步到 iCloud

• 支持 Face ID / Touch ID 保护

• 切换应用时自动模糊内容

如何删除所有数据？

您可以在 设置 → 数据管理 → 清空所有历史 中删除所有会话记录。

卸载应用也会删除所有本地存储的数据。

🔧 问题排查

手表数据没有同步到手机？

请检查以下几点：

1. 确保 iPhone 和 Apple Watch 在通信范围内

2. 检查设置中的"手表连接"状态

3. 尝试在 iPhone 上下拉刷新

4. 重启 iPhone 和 Apple Watch 上的应用

心率数据显示不完整？

这可能是因为：

• Apple Watch 佩戴不够紧，导致心率采集间断

• 活动时间过短，数据不足以分析

• 建议确保手表紧贴手腕，且活动持续至少5分钟

Face ID 解锁失败怎么办？

如果 Face ID 解锁多次失败，您可以：

1. 确保面部在摄像头可见范围内

2. 移除遮挡物（如口罩）

3. 如果持续失败，可以使用设备密码解锁
